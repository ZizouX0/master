## How this was built
Parallel research agents ran in three waves — funding-first (Erasmus Mundus catalogue + government schemes), program-first by track, and a region sweep covering every European country — followed by a verification pass that re-checked each program's deadline, tuition, funding, and Tunisian eligibility against its **official** page. Aggregators were used only as leads. Nothing was invented; unconfirmed facts are marked `UNVERIFIED` / `Check`, and unpublished 2027 deadlines are labelled `PRIOR CYCLE — confirm new date`.
