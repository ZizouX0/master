# 04 — Dossier checklist (national study visa, filed in Tunis)

> Confirm against the embassy's own current list first — write to **`Emb.tunez@maec.es`**.
> BLS in Tunisia handles Schengen visas (≤90 days) only; a study stay over 90 days is a
> **national (type D) visa filed with the embassy**.

## The file

| ✔ | Document | Watch out for |
|---|---|---|
| ☐ | **Solicitud de visado nacional** — official form, signed | Download the current version; old forms get rejected |
| ☐ | **Passport** — valid for the whole stay, 2 blank pages, issued within the last 10 years | Renew now if it expires within ~15 months |
| ☐ | **Photo** — recent, white background, passport format | |
| ☐ | **Carta de admisión** from the language school | Must state **≥20 h/week, presencial**, dates, fees paid → template [`02`](./02-email-escuela-idiomas.md) |
| ☐ | **Correspondence with a university about the master's** | Supporting, not required — but it is what makes the itinerary credible → template [`05`](./05-correspondencia-universidad.md) |
| ☐ | **Carta de motivación y plan de estudios** | Signed, dated, Spanish → template [`03`](./03-plan-de-estudios.md) |
| ☐ | **Medios económicos** — ~**€600/month** (IPREM 2026, frozen) × months of stay ≈ **€7,200/year** | Bank statements over **6+ months**, not a fresh balance. If a parent sponsors you: notarised undertaking + their bank statements + proof of relationship |
| ☐ | **Seguro médico** — private, full cover, valid in Spain, **no co-payments, no waiting period, no cap** | Travel insurance is refused. Ask the insurer for a certificate that uses those exact words |
| ☐ | **Certificado de antecedentes penales** — Tunisia (and any country lived in for the last 5 years) | Stays **>180 days** only. Apostilled + sworn translation into Spanish. **Usually valid 3 months — order it late, not first** |
| ☐ | **Certificado médico** — no diseases per the 2005 IHR | Standard wording; the embassy usually publishes the exact text. Also short-dated |
| ☐ | **Alojamiento** — residence booking, rental contract or the school's accommodation letter | |
| ☐ | **Degree certificate + transcript** | Sworn translation into Spanish. Not always required for a language course, but it is what makes the master's story land |
| ☐ | **Visa fee** | Paid as the embassy directs |

**Every document: original + one photocopy.** Translations by a *traductor jurado*. Foreign
public documents (penales, degree) need the **apostille** — Tunisia has been in the Hague
Apostille Convention since March 2018, so it is an apostille, not full legalisation.

## Order of operations

```
now ──────────────► send template 01 to universities (slow, start first)
                    send template 02 to language schools, compare timetables
                    open/feed the bank account that will show the €7,200
                    check passport expiry
~4 months out ────► choose the school, pay, get the carta de admisión
                    write template 03 around the real dates
                    apostille + sworn-translate the degree
~2 months out ────► email Emb.tunez@maec.es for the appointment + current checklist
~6 weeks out ─────► order antecedentes penales and certificado médico (they expire)
                    buy the insurance
appointment ──────► file it
after arrival ────► empadronamiento, then TIE within 30 days (stays over 6 months)
60 days before
the permission
expires ──────────► prórroga with the master's admission letter
```

## The three ways this file fails

1. **The language course does not really do 20 presencial hours.** Verify from the timetable,
   not the marketing page.
2. **The money looks assembled.** A balance that appeared last month reads as borrowed. Six
   months of history is the fix, and it is the one thing you cannot arrange late.
3. **The documents contradict each other.** School letter says 15 September, your plan says
   1 October, the insurance runs from 20 September. Read the finished file end to end as if
   you were the officer, once, before you seal it.
